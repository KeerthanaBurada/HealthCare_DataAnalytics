# Experiment 1: Exploratory Data Analysis on Heart Disease Dataset

## Aim

To perform Exploratory Data Analysis (EDA) on a heart disease dataset to
understand patient characteristics, identify patterns, and analyze
relationships between health parameters and heart disease occurrence.

## Dataset Description

The dataset contains medical attributes of patients such as age, gender,
blood pressure, cholesterol level, heart rate, and heart disease status.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Procedure

1. Load the heart disease dataset using Pandas
2. Inspect dataset structure and data types
3. Check for missing values
4. Generate descriptive statistics
5. Visualize distributions of key features
6. Analyze relationships between attributes and heart disease
7. Interpret insights from visualizations

## Result

EDA revealed relationships between age, cholesterol, blood pressure,
and heart disease. Certain features showed strong variation between
patients with and without heart disease.

## Conclusion

Exploratory Data Analysis helps in understanding healthcare data and
acts as a foundation for further statistical analysis or predictive
modeling.
